# Profile photo asset

Place your professional portrait here with this exact filename:

```
src/assets/profile/rajapandu-profile.png
```

Supported extensions: `.png`, `.jpg`, `.jpeg`, `.webp`, `.avif`.

The hero applies CSS treatments automatically (dark overlay, cyan rim light, edge
vignette, bottom fade) so the bright office background blends into the dark theme.
A styled `RM` monogram is shown as a placeholder until the photo exists.
